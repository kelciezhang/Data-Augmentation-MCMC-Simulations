# Data-Augmentation-MCMC-Simulations
Supporting simulation code for the paper "Fast Mixing of Data Augmentation Algorithms: Bayesian Probit, Logit, and Lasso Regression" by Holden Lee and Kexin Zhang
### User guide
1. Simulation scripts: see DA.py for ProbitDA and LogitDA, and LassoDA.py for LassoDA
2. Simulation outputs: see probit.zip and logit.zip for average-case ProbitDA and LogitDA, probit_imbalanced.zip and logit_imbalanced.zip for worst-case ProbitDA and LogitDA, and lasso_result.zip for LassoDA
3. Notebooks for Generating Plots: see summary-probit-and-logit.ipynb for ProbitDA and LogitDA, and summary-lasso.ipynb for LassoDA
4. Plots: see plot.zip
